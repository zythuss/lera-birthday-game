# Для тебя ♡

Адаптивная розовая игра на день рождения. Настоящая 3D-модель из вокселей основана на `body.png` и `face.png`. Открытка: `public/otkritka.jpg`.

## Запуск

```sh
npm ci
npm run dev
```

## Размещение на Render

1. Загрузите проект в GitHub (без `node_modules` и `dist`). Личные фотографии `body.png` и `face.png` можно не загружать: игра их не использует во время работы.
2. На Render создайте **Static Site** из этого репозитория либо **Blueprint** с файлом `render.yaml`.
3. Build Command: `npm ci && npm run build`.
4. Publish Directory: `dist`.

Сервер, база данных и ключи API не нужны. `npm run build` создаёт готовый сайт в `dist`.

## Правила

Меню → закрытая валентинка → 30 секунд стрельбы → босс → открытка. Цельтесь мышью и нажимайте на цель или пробел. На телефоне касайтесь цели. Босс имеет 5 HP. Он замахивается ровно одну секунду. Уклоняйтесь в противоположную сторону атаки кнопками или A/D, ←/→. После успешного уклонения есть 2,5 секунды для одного попадания. Если цель полностью улетает за верхний край экрана, появляется проигрыш с кнопкой повторной попытки. Ошибка при уклонении от босса позволяет попробовать на следующем замахе. Пауза останавливает таймер; уход из вкладки включает паузу автоматически.

3D-героиня требует WebGL; при его отсутствии отображается запасной персонаж, а игра остаётся доступной. Шрифты загружаются из Google Fonts с локальной заменой при отсутствии сети. Звуки синтезируются в браузере и включаются отдельной кнопкой.
